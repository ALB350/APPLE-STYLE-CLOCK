HORLOGE — Windows

Ouvrez Horloge-sombre.exe (aucune installation requise ; Windows 10/11, .NET Framework 4.8).

• Horloges du monde : ajoutez des villes et comparez les heures.
• Alarmes : heure, nom, jours de répétition, son et rappel de 9 minutes.
• Chronomètre : démarrer, arrêter, reprendre, tours et remise à zéro.
• Minuteurs : plusieurs décomptes, pause/reprise et durées récentes.

L'application doit rester ouverte et le PC éveillé pour sonner. En réduisant
la fenêtre, les alarmes et minuteurs continuent. Fermer quitte l'application.
Une échéance dépassée pendant la veille sonne au retour, si l'appli est ouverte.
Les réglages sont sauvegardés dans %LOCALAPPDATA%\HorlogeWindows\settings.xml.
Les sons sont des tonalités originales synthétisées, pas les sons Apple.
Interface inspirée d'Horloge ; application indépendante, non affiliée à Apple.

Raccourci : Espace démarre/arrête le chronomètre lorsque cet onglet est actif.
Code source et script de compilation inclus dans le dossier Source.
Le fichier README.md contient la présentation complète pour GitHub.
